# Fixed Rules

These should not be changed unless the user explicitly changes them.

1. The app does not implement the tabletop game itself.
2. Human-vs-human matching is preferred.
3. Only the immediate last opponent is avoided when possible.
4. Ignore that avoidance rule if candidate count is too small.
5. Table count is fixed at 5.
6. Bet amount is fixed by configuration.
7. Bet is deducted only when both players confirm start.
8. If a player has fewer chips than the fixed bet, the match is all-in at the smaller stack.
9. No side pots.
10. Winner claim needs opponent approval.
11. Rejection returns the match to in-progress.
12. Cancel is allowed only before match start.
13. Admin UI is separate from participant UI.
14. Participant UI is smartphone-first.
15. Admin UI is desktop-first.
