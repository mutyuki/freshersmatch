# Admin Layout Notes

Use `layout.pen` as the visual baseline.

## Admin pages

- desktop-first
- multi-column layout is allowed
- panels and tables are preferred
- information density is higher than participant UI

## Monitor ranking

- display-only
- larger typography
- visible from a distance
- no editing controls

## Improve beyond layout.pen

- make destructive actions more obvious
- improve scanability of tables
- make dashboard summaries feel more actionable
